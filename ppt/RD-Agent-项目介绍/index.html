05 / 09
智能体 ③④ · Runner 回测 + Summarizer 反馈

闭环：跑过才知道对不对，反馈沉淀成经验

Runner 负责真跑，Summarizer 负责总结——所有结果写入 Trace，下一轮直接用，让系统越跑越聪明。

Runner · 回测执行

  • SOTA 因子继承：跑新因子前自动加载同 model 下历史最优因子集（"抄作业"不重造轮子）
  • 因子去重/合并：相似度 >80% 的因子自动合并，避免重复劳动
  • 真实回测：调用 qlib 跑出 IC / IR / 年化 / 夏普 4 项硬指标

Summarizer · 4 维反馈

  • ① 代码可执行性（能不能跑）
  • ② 信号质量（IC、IR 是否达标）
  • ③ 与当前 SOTA 对比（是否超越）
  • ④ 下一步自然语言建议（往哪改）

每轮 Trace 写入 log/，HypothesisGen 与 CoSTEER 都能检索 → 经验不丢失。
