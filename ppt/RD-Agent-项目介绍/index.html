06 / 09
智能体 ③④ · Runner + Summarizer

闭环：真跑才知道好坏，反馈沉淀成经验

Runner 实干（抄 SOTA 作业 → 去重 → qlib 真实回测），Summarizer 做教练（4 维反馈），所有结果入 Trace 反哺下一轮。

🏃 Runner · 回测执行

  • SOTA 继承：跑新实验前自动“抄作业”——加载同 model 下历史最优因子集 / 模型超参作为基础
  • 因子去重/合并：余弦相似度 >80% 的因子自动合并，避免重复劳动
  • Docker + qlib 真实回测：隔离环境产出 IC / IR / 年化 / 夏普 4 项硬指标

📋 Summarizer · 4 维反馈

  • ① 可执行性——能不能跑（报错定位到行）
  • ② 信号质量——IC / IR 是否达标
  • ③ vs SOTA——是否超越当前最优
  • ④ 下一步建议——自然语言改方向
